# 📧 Project 01 - Linux Mail Server 

## Overview

This project demonstrates the deployment and configuration of a local mail server using **Ubuntu Server**, **Postfix**, **Dovecot**, and **Roundcube Webmail**. The server was configured to provide email sending, receiving, and webmail access within a local network environment.

The project focuses on Linux system administration, mail service configuration, troubleshooting, and validating email communication between users.

---

## Objectives

- Deploy a local mail server on Ubuntu Server.
- Configure Postfix as the SMTP server.
- Configure Dovecot for IMAP services.
- Install and configure Roundcube Webmail.
- Create and manage local mail users.
- Test email communication within the local network.

---

## Technologies Used

- Ubuntu Server
- Postfix
- Dovecot
- Roundcube Webmail
- Apache2
- PHP
- MariaDB
- Linux CLI
